# Security policy

Only the latest release of omp-rewrite gets security fixes.

To report a vulnerability, use GitHub's private reporting: [open a draft security advisory](https://github.com/zPeppOz/omp-rewrite/security/advisories/new). Please don't open a public issue. Expect a first reply within a week.

omp-rewrite runs inside omp with the same permissions as omp itself. It sends your draft and the current conversation to the model configured in your session and never executes tool calls. Report issues in omp itself to [oh-my-pi](https://github.com/can1357/oh-my-pi/security).
